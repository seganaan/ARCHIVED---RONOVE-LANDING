# Ronove Technologies — Landing Page

> 🚧 **Status: Incomplete / not actively developed.**
> This landing page was started and then set aside. It is published as-is to show the work so far. It will stay unfinished until further notice (which is unlikely).

A responsive, dark-mode-aware landing page for **Ronove Technologies**, a web development and software studio. Only the first few sections were built.

**Tagline:** *Architecting the Digital Future.*

---

## What's built so far

| Section | Description |
|---------|-------------|
| **Header** | Fixed top bar with a blinking-cursor `>R_` logo, nav links (Home, Services, Portfolio, About Us) and a **Contact Us** button. Nav links are hidden on small screens |
| **Hero** | Full-screen section with a large `clamp()`-sized Syne headline over a tinted background image. Desktop and mobile use different background photos |
| **Skills strip** | A tinted band listing the core stack: HTML, CSS, Node.js, Zero-Trust |
| **Core Expertise** | Section header and a first **Web Development** card (Custom Apps, E-Commerce, React/Next.js tags). The remaining grid rows are empty placeholders |

### Not built yet
- Services, Portfolio and About Us pages / sections
- Working navigation and a Contact form
- More expertise cards, footer
- The JavaScript behaviour (`js/script.js`)

## Tech stack

| Layer | Technology |
|-------|-----------|
| Markup | HTML5 |
| Styling | Tailwind CSS **v4.2.2** (compiled output in `css/style.css`) |
| Fonts | Syne (headings), plus JetBrains Mono, Manrope and Plus Jakarta Sans, all self-hosted `.ttf` variable fonts |
| Icons | Font Awesome (self-hosted) |
| Theming | Light and dark mode through `prefers-color-scheme` |

### Design tokens

| Token | Value |
|-------|-------|
| Primary green | `#134E4A` |
| Secondary green | `#34666F` |
| Accent / light green | `#2DD4BF` |
| Dark ashy (dark-mode text) | `#8c9ab1` |
| Dark background | `#001016` |

Responsive breakpoints used: default (mobile), `lg` (≥ 64rem) and `xl` (≥ 80rem).

## Running locally

No build step is needed to view it. Serve the folder with any static server:

```bash
git clone <this-repo-url>
cd <repo-folder>
python3 -m http.server 8000
```

Then open `http://localhost:8000/`.

### Rebuilding the CSS (optional)
`css/style.css` is generated by Tailwind CSS v4. If you have the Tailwind source (an input CSS file that imports Tailwind), rebuild with the Tailwind CLI, scanning `index.html` for classes:

```bash
npx @tailwindcss/cli -i ./src/input.css -o ./css/style.css --watch
```
